在此记录一下我这个git config了一个用于清除本地已经合并到master/main的所有分支的脚本

然后不需要切换分支，挺方便的

## 先设置预览版（看哪些会被删）

```bash
git config --global alias.cleanup-preview '!f() { target=${1:-master}; git fetch origin "$target" && echo "以下分支已合并到 origin/$target，将被删除：" && git branch --merged "origin/$target" | grep -v "\*" | grep -v "$target" || echo "没有可删除的已合并分支"; }; f'
```

## 再设置删除版（直接删除）

```bash
git config --global alias.cleanup '!f() { target=${1:-master}; git fetch origin "$target" && branches=$(git branch --merged "origin/$target" | grep -v "\*" | grep -v "$target") && [ -n "$branches" ] && echo "$branches" | xargs git branch -d || echo "没有可删除的已合并分支"; }; f'
```

## 使用方式

- git cleanup-preview —— 预览基于 master 的可删除分支

- git cleanup —— 删除已合并到 master 的分支

- git cleanup-preview main —— 预览基于 main 的可删除分支

- git cleanup main —— 删除已合并到 main 的分支

## 工作原理

关键改动是 --merged "origin/$target"，它会跟远程跟踪分支比较，而不是本地分支。这样：

- 不需要切换分支

- 不需要 pull（只需 fetch 更新远程信息）

- 在你当前开发分支上就能直接操作

> 注意：这个只删除了本地分支。
